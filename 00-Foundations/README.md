# Module 00 — Foundations

> The vocabulary and mental tools you'll use in **every** later module. Don't skip this.

If you only half-understand Big-O and recursion, everything afterward feels like memorization.
Spend real time here and the rest of the course clicks into place.

- Look at a loop or recursive function and state its time/space complexity.
- Read and write basic recursion, and reason about the call stack.
- Use bitwise operations for sets, flags, and common interview tricks.
