# Module 01 — Linear Structures

> The building blocks. Every other structure is built on top of these.

Linear structures store elements in a sequence. Master how each one trades off access speed,
insertion speed, and memory — that trade-off is the heart of choosing a data structure.

## Contents

| # | Topic | One-liner |
|---|-------|-----------|
| 01 | [Arrays](01.Arrays.md) | Contiguous memory; O(1) access, costly inserts |
| 02 | [Strings](02.Strings.md) | Arrays of characters, immutability, StringBuilder |
| 03 | [Linked Lists](03.Linked-Lists.md) | Nodes linked by pointers; cheap inserts, slow access |
| 04 | [Stacks](04.Stacks.md) | LIFO — last in, first out |
| 05 | [Queues & Deques](05.Queues-and-Deques.md) | FIFO and double-ended variants |
| 06 | [Hash Tables](06.Hash-Tables.md) | O(1) average lookup by key — the secret weapon |

## After this module you can

- Pick the right linear structure for a problem and justify it with complexity.
- Implement each from scratch and use the C# built-ins (`List<T>`, `Stack<T>`, `Queue<T>`, `Dictionary<T,K>`).
- Solve classic problems with two pointers, hashing, and stack/queue patterns.
