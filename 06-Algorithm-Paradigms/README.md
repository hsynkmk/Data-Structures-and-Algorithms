# Module 06 — Algorithm Paradigms

> **The most important module for problem-solving.** Structures store data; *paradigms* solve
> problems. This is where you learn to actually attack an unfamiliar question.

Each paradigm is a way of thinking. Once you internalize them, most interview and contest
problems become "oh, this is a sliding-window problem" or "this is DP."

## Contents (build in this order)

| # | Paradigm | The core idea |
|---|----------|---------------|
| 01 | [Two Pointers & Sliding Window](01.Two-Pointers-and-Sliding-Window.md) | Move indices smartly instead of nested loops |
| 02 | [Prefix Sums](02.Prefix-Sums.md) | Precompute so range queries become O(1) |
| 03 | [Divide & Conquer](03.Divide-and-Conquer.md) | Split → solve parts → combine |
| 04 | [Backtracking](04.Backtracking.md) | Try, recurse, undo — explore all possibilities |
| 05 | [Greedy](05.Greedy.md) | Take the locally best choice; prove it's globally optimal |
| 06 | [Dynamic Programming](06.Dynamic-Programming.md) | Remember overlapping subproblems instead of recomputing |

## After this module you can

- Replace many O(n²) brute forces with O(n) two-pointer / sliding-window solutions.
- Tell when greedy is safe vs when you need DP.
- Turn a recursive brute force into memoized then tabulated DP, methodically.

> Prerequisite: [Recursion](../00-Foundations/03.Recursion.md) is essential before backtracking and DP.
