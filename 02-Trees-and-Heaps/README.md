# Module 02 — Trees & Heaps

> From flat sequences to hierarchies. This is where recursion really pays off.

Trees model hierarchy and enable O(log n) operations when balanced. Heaps give you the
smallest/largest element instantly. Union-Find and segment trees are the "expert" structures
that make certain problems suddenly easy.
