# Module 03 — Graphs

> Anything with *relationships* — maps, networks, dependencies — is a graph.

Graphs generalize trees (a tree is just a graph with no cycles and one path between nodes).
Once you can represent a graph and traverse it, a huge family of problems opens up.

## After this module you can

- Choose the right representation for a graph problem.
- Apply BFS/DFS to connectivity, cycles, and ordering problems.
- Compute shortest paths and minimum spanning trees, and know which algorithm fits.
